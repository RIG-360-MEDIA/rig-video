# Findings B: pyautoflip / idopinto / FrameShift / AutoFlip (research agent, 2026-11-19)
pyautoflip (MIT, CPU-only, no tests): parts only. Scene detection skipped for clips <~30 s (core/processor.py:196-201) -> cuts in short clips ignored. Default mode: faces/people only; fire/smoke/vehicles/buildings -> centre (frame_crop_region.py:57-76). Saliency mode maps 5 samples to frames 0-4 -> static per scene (saliency_cropper.py:128-134). Split misfires on any sample with 2 far faces (272,306). Opus audio dropped, mp4v, double encode (utils/video.py:77-86,165). Output source height (606x1080). No crop path/confidence. InsightFace non-commercial but mediapipe_face_detector.py ships unused. UNISAL code Apache-2.0; weights trained on research datasets -> legal check. Reuse: UNISAL wrapper (non-person fallback), blur padding, split renderer with strict trigger.
ai-video-reframing (MIT; YOLO11m+BoT-SORT AGPL): best skeleton. Per-frame x(t) as data with mode + reason ("no track survived filtering"), one-pass ffmpeg render, hold/follow/snap-to-centre/ease/Gaussian logic, face-offset aim, YuNet MIT. No shot detection (drifts across cuts); one subject/clip, no split/pad; non-COCO + graphics -> centre; portrait narrower than 9:16 crashes ffmpeg; detection cache keyed on filename (detect.py:192,246) -> cross-job reuse bug. AGPL confined to Detector.track(): moderate swap.
FrameShift (MIT; YOLO AGPL): not engine. One static crop per scene cut-aligned; --output_height 1920; fit-with-blur; SHA-256 model gate. Crop = union of detections (two people -> gap); small subject zoom ~12x; only first 150 frames/shot; 'default' class weight ignored (detection.py:277); mp4v; latent end-of-video crash (main.py:359-377); no data out. Reuse: fit-with-blur fallback, checksum gate.
Google AutoFlip ideas missing elsewhere: letterbox + solid border detection (not side bars -> pillarbox is ours), SWEEPING pan when <40% frames detected, forced re-plan every 600 frames for long takes, pad instead of cut when required subjects don't fit, per-scene frame_success_rate + is_padded, per-frame ExternalRenderFrame crop path (schema to copy).
Recommended combo: ai-video-reframing Director per shot (+velocity limit, AGPL detector/tracker swapped) <- shot detection + border/pillarbox removal; YuNet faces + UNISAL saliency for person-less shots; per-shot fallbacks by detection success rate (fit-with-blur graphics, strict split, sweep/hold-centre wide); AutoFlip-style per-frame crop path + per-scene summary JSON.
