# Findings C: clipper layout engines (from the research agent, 2026-11-19)
openshorts (MIT; cloud/ separate): best base. TransNetV2 shots; per-scene 5-frame MediaPipe face sampling (avg 0.5-1.2 faces -> TRACK, else GENERAL blur), short-scene smoothing (main.py:567-638); vertical passthrough (reframe_v2.py:69,689); SPLIT gated (2 faces >=4.5% w, >=20% apart, >=50% co-presence, scene >=2.5 s; split_layout.py); heavy-tripod camera, 3-confirm jumps, snap on cuts (main.py:116-268); GPU NVDEC->CUDA->NVENC; legacy fallback; per-frame crop x + layout ranges. Gaps: no-face scenes all GENERAL (0.42 height ratio crops ~24% width, maps need 0.32; reframe_v2.py:130); no black-bar detection; tickers/logos stay. Gemini only for optional layout picker / screen check / subtitle band, all with local fallback. YOLOv8 (AGPL) only a fallback (main.py:470), removable.
reelsaw (AGPL: copy no code; re-implement ideas from docs/LAYOUTS.md): face <60% frames -> fit; 3+ people -> fit; second face >=8% tall -> split; small/corner face -> stack (layout.ts:193-245); static faces dropped (stills -> fit); OCR text-heavy -> fit; persistent same-position text across shots = overlay, blurred and excluded from crops (render.ts:375-460) - only repo doing this. Models permissive (UltraFace MIT, PP-OCRv4 Apache). Risk: wide shot w/ small face -> stack with upscaled face. No letterbox/pillarbox handling. No LLM.
Reframe (MIT): weak; claudeshorts always crops 9:16 (YuNet -> motion -> centre), no letterbox, no scene cuts (smooths across cuts), audio-based multi-speaker; ViNet-S non-commercial. Borrow: select_dominant, motion-run centroid, median->EMA smoothing, "degraded" notice.
Autocrop-vertical: no licence (all rights reserved) + AGPL YOLO; one frame per scene; sys.exit when no scenes (main.py:504). Nothing to borrow.
RetargetVid/SmartVidCrop: 2021 TF1.14; MIT file with placeholder copyright; padding fallback off by default and broken (VD['mean_sal'] never set :2312; coverage loop zero iterations :1310-1334). Idea = right confidence signal: salient-mass coverage of best 9:16 window -> fall back to fit.
Recommendation: openshorts minus YOLO + ffmpeg cropdetect bar detection + reelsaw ideas re-implemented (static-face drop, crowd->fit, text-heavy->fit, persistent-text blur/avoid via PP-OCRv4) + per-shot coverage confidence with fit fallback (0.32) + motion-centroid crops for face-less action w/ camera-motion compensation; local qwen3-vl instead of Gemini only if needed.
