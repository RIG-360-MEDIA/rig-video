# Findings A: auto-vertical-reframe family (research agent, 2026-11-19)
All three: MIT code but AGPL Ultralytics models; every frame cropped (no blur-fill/letterbox/split); no bar or graphics detection; no crop-path export (per-frame rect + confidence computed internally, ~20 lines to export).
KazKozDev (4 commits, 25*, 2026-10-04): one 3678-line file, macOS-centric, no tests. Locked `movie` mode (static crop per shot, centre for wide/empty) is the best idea for news; follow mode weak. Reuse locked planner + headroom rules. DeepGaze via torch.hub trust_repo=True master (unpinned); mp4v intermediate re-encode; VFR audio drift.
darkvertex (31 commits, 2026-10-27): same logic, Linux/CUDA packaged: Docker NVENC, FP16, prefetch, one-pass ffmpeg pipe, summary dict, CI. Reuse ffmpeg writer + encoder probe. Audio copied as-is fails on Vorbis. Shared MediaPipe Pose across people (both).
wide2short (65 commits AI-written, 2026-11-09): best camera maths (spring), two-person fit check, inline cut detector, ~386 tests, no CI; VFR clip crashes default decoder; AGPL deeply wired (734-line seg module); Python 3.13; no locked mode. ~12 fps on 4K60 on T4.
Per footage: no person -> pans/zooms to handcrafted saliency (drifts onto text/tickers); graphics -> cropped unreadable; wide/crowd -> follow zooms on random person, movie centres; two far people -> cut or gap (wide2short frames one); speaker switch none; vertical input ok but default zoom >=5% trims; square loses 44%; pillarbox bars leak / blurred copy can win ranking; letterbox bands stay; cuts: PySceneDetect hard cut (fades missed), darkvertex 1-3 frames off, wide2short exact; no stabilisation.
Licences: DeepGaze MR code MIT (weights LEDOV + VGG19, low risk); MediaPipe Apache; PySceneDetect/TorchCodec BSD-3. AGPL swap easy for KazKozDev/darkvertex (~150-300 lines adapter: RF-DETR/YOLOX + MIT ByteTrack), hard for wide2short. UNISAL slots in.
Suggested combo: preprocess (CFR, bar removal, vertical passthrough, shot classify graphics/wide/interview/action) -> per-shot mode (locked planner for interviews/panels, wide2short camera maths for follow, new blur-fill/fit for graphics/wide/low-confidence) -> non-AGPL detector + MediaPipe -> JSON crop path + confidence -> darkvertex one-pass NVENC, AAC.
